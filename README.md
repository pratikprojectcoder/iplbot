Overview

IPL Bot is a full-stack cricket analytics and match prediction platform built using Python, FastAPI, Streamlit, and React. The project processes historical IPL datasets to generate advanced team, player, and venue insights while using machine learning models to predict match outcomes.

The platform combines:

Data engineering pipelines
Machine learning prediction models
REST API backend
Interactive dashboards
Real-time scorecards and analytics

This project demonstrates practical applications of:

Machine Learning
Data Analytics
Backend Development
